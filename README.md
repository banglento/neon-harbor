# Neon Harbor

Mara Velez knows every shortcut in Solmar Bay, a bright coastal city where an old friend’s “one last job” pulls her courier route into escalating trouble. Make the handoffs, outrun the harbor police, and earn enough cash and respect to choose what comes next in an original low-poly open-world crime story.

Features

- Three chained story missions: First Run, Three Drops, and Harbor Lights, followed by a story-complete screen.
- Repeatable courier deliveries for cash and respect, with progress saved in the browser.
- Explore the sunlit streets, harbor and neighborhoods on foot or behind the wheel.
- Arcade driving, pedestrian crowds, reactive traffic, police pursuit, wanted level and cartoonish combat-lite.
- A live minimap, procedural WebAudio effects and an ambient synth loop.
- Offline static game files; no runtime network requests or build step.

Controls

- WASD: move on foot or steer/drive
- Mouse drag: orbit the camera
- Shift: sprint
- E: enter or exit a nearby parked car
- F or click: shove a nearby pedestrian
- Q: start a courier side run
- P or Esc: pause/resume
- M: mute/unmute
- Space: brake while driving

Run locally with Node 22:

1. From the repository root, run `node serve.ts`.
2. Open http://localhost:8080.
